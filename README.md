🛍️ E-commerce Website
A fully functional online store built using the MERN stack (MongoDB, Express, React, Node.js), offering users the ability to browse products, add them to the cart, and complete purchases with payment integration.

🚀 Tech Stack
Frontend: React, Redux, React Router, Bootstrap

Backend: Node.js, Express.js

Database: MongoDB

Authentication: JWT (JSON Web Token)

Payment Gateway: Stripe (or placeholder)

🧰 Features
🛒 Product Listing: Display products with categories and filters

👤 User Authentication: Register, log in, and manage profiles with JWT-based authentication

🧺 Shopping Cart: Add, remove, or update product quantity in the cart

💳 Checkout: Payment integration with Stripe (or placeholder)

🛠️ Admin Dashboard: Manage products, view orders, and update inventory

📦 Order Tracking: View order history and status updates
